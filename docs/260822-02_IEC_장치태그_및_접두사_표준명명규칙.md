# 전장설계 IEC 표준 장치 태그(Device Tag) 및 접두사(Prefix) 표준 가이드

- **문서 번호**: 260822-02
- **관련 규격**: IEC 81346-1 / IEC 81346-2, IEC 60204-1, IEC 61346
- **작성일자**: 2026-08-22

---

## 1. IEC 81346 참조 지정자(RDS: Reference Designation System) 구조

IEC 국제 표준에서는 장치 식별을 위해 계층적 접두 기호(Prefix Sign)를 사용합니다.

| 기호 | 구분 (Aspect) | 의미 | 예시 |
| :---: | :--- | :--- | :--- |
| **`=`** | **기능 (Function)** | 장비의 기능 또는 서브 시스템 | `=CONV1` (1번 컨베이어) |
| **`+`** | **위치 (Location)** | 장치/부품이 설치된 물리적 위치 | `+CP1` (제어반 1), `+FLD` (현장/기계부), `+OP1` (조작반) |
| **`-`** | **장치 (Device/Component)** | 개별 전기 부품 식별 태그 | `-KM1` (전자접촉기 1), `-QF1` (차단기 1) |
| **`:`** | **단자 (Terminal)** | 부품의 개별 핀/단자 번호 | `:13`, `:A1`, `:X1` |

> **통합 표현 예시**: `=SYS1+CP1-KM1:A1`  
> *(1번 시스템의 제어반 1에 위치한 마그네트 1번의 코일 A1 단자)*

## 2. IEC 81346-2 기준 주요 장치 접두사 (Prefix / Letter Codes)

전장설계 실무에서 가장 널리 사용되는 IEC 표준 1문자 및 2문자 코드 분류입니다.

### 🔌 1) 전원, 보호 및 개폐 기기
| 태그 (Prefix) | 기기 명칭 (Equipment Name) | 실무 적용 예시 |
| :--- | :--- | :--- |
| **QF / QM** | 주회로 차단기 (Circuit Breaker) | 메인 차단기(MCCB), 배선용 차단기, 모터 보호 차단기(MPCB) |
| **FC / MCB** | 제어회로 차단기 / 소형 차단기 | SMPS 1차/2차측 미니어처 차단기(MCB) |
| **FU / F** | 퓨즈 (Fuse) | 전원 퓨즈, 유리관 퓨즈 |
| **FA / FR** | 과부하 계전기 (Overload Relay) | 열동계전기(Thermal Relay), EOCR |
| **FD / SPD** | 서지 보호기 (Surge Protective Device)| 전원단 서지 억제기(Surge Killer/SPD) |
| **QS / Q** | 단로기 / 로터리 스위치 (Disconnector)| 도어 연동 주전원 스위치, 안전 스위치 |
| **KM / QA** | 주회로 전자접촉기 (Main Contactor) | 모터/히터 구동용 마그네트 스위치 |
| **KA / K** | 보조 계전기 (Auxiliary / Control Relay)| 제어용 파워 릴레이, 마이콤 릴레이, 타이머 릴레이(KT) |
| **KS / KF** | 안전 계전기 (Safety Relay Module) | 비상정지/도어용 안전 릴레이 모듈 |
| **TC / T** | 변압기 (Transformer) | 제어용 트랜스(380V -> 220V/110V) |
| **GS / G** | 전원공급장치 (Power Supply) | 스위칭 모드 파워 서플라이(SMPS DC 24V) |
| **GB** | 배터리 / 축전지 (Battery) | UPS 배터리, 백업 배터리 |
| **ZF / FL** | 노이즈 필터 (Noise Filter / EMC) | 주전원 인입 노이즈 필터, 통신 필터 |

## 3. SkyCAD 실무 권장 명명 조합 규칙

SkyCAD에서 자동 넘버링 룰(Renumbering Rule)을 설정할 때 권장하는 조합 형식:

```text
[장치접두사(Prefix)] + [시트번호(Sheet No.)] + [순번(Index)]
```
* **예시**:
  * 2번 시트 첫 번째 차단기: **`QF201`** 또는 **`QF2.1`**
  * 3번 시트 릴레이: **`KA301`**, **`KA302`**
  * 4번 시트 솔레노이드 밸브: **`YV401`**, **`YV402`**
  * 현장 단자대: **`TB_IO`**, **`TB_PWR`**
