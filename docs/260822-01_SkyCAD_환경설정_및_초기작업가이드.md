## 1. SkyCAD 환경 경로 설정 (핵심 규칙)
* **설정 항목**: `SkyCAD Explorer` -> `Current Environments Path`
* **지정 경로**: `C:\Workspaces\study\SkyCAD_Env`
* **주의사항**: `Standard Environment` 폴더가 아닌 **그 상위 폴더**를 지정해야 하위의 환경 폴더들이 정상 로드됨.

---

## 2. 전장 회로도 기본 작업 흐름
1. **프로젝트 생성**: `Create/Add` -> `New Project` (이름 지정)
2. **프로젝트 저장**: `Home` -> `Save As` 로 관리 대상 폴더에 `.SkyCadFile` 저장
3. **시트 추가 및 표제란 기입**: `Create/Add` -> `New Sheet` 후 프로젝트 속성에서 도면 번호/작성자 입력
4. **회로도 작성**: `IEC Symbol Library`에서 부품 배치, 단축키 `C`로 배선
5. **카탈로그 매핑**: `Catalogue tools` -> `Assign from Catalogue`로 제조사 모델 지정
6. **일괄 넘버링**: `Run Wire Renumbering`, `Run Component Renumbering`
7. **보고서 출력**: `Add BOM`, `Generate Terminal Strip Layout`, `PDF Export`
